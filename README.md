# Sweldo

Landing page for **Sweldo**, invoices that send themselves. Built for Filipino freelancers and VAs.

## Files
- `index.html`: the whole landing page (no build step needed)

## Before going live
- Waitlist signups go to Formspree form `mgaoaqeb` (https://formspree.io/f/mgaoaqeb).
- Replace the placeholders: `[Client name]`, `₱[converted amount]`.

## Hosting
Turn on GitHub Pages: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
The site appears at `https://walnaught.github.io/Sweldo/` after a minute or two.
